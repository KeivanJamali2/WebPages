Help & Documentation

Learn how to use the HamiAnalyzer platform

Getting Started

1. Upload Your Data

Navigate to the Upload Data page and select a ZIP file containing your raw data files. The ZIP should contain files in the format:

  • file_i_j.txt - Message data files
  • workflow_i_j.txt - Workflow data files

Where i is the Hami ID and j is the request number.

2. Process the Data

After uploading, you'll be redirected to the Process Data page. You can:

  • Specify Hami IDs to process (comma-separated)
  • Leave empty to auto-detect all IDs
  • Click "Process Data" to organize files into the database
3. Run Analysis

Visit the Analyze page and click "Run All Analyses" to generate:

  • Visualization plots (PNG images)
  • Statistical data (CSV files)
  • Comprehensive metrics
4. View Results

Access your results through:

  • Plots - View and download visualization images
  • Downloads - Download detailed CSV files

Database Management

Adding More Data

You can continuously add more data to your database:

  1. Upload a new ZIP file
  2. Process the data
  3. New data will be merged with existing data
  4. Re-run analysis to include new data
Clearing the Database

To start fresh:

  1. Go to Database page
  2. Click "Clear Database" in the Danger Zone
  3. Confirm the action
  4. Upload and process new data
Warning: Clearing the database is permanent and cannot be undone!

Frequently Asked Questions

Q: What file formats are supported?

Only ZIP files containing properly formatted TXT files are accepted.

Q: How large can my upload be?

Maximum file size is 500 MB per upload.

Q: How long does analysis take?

Typically 2-5 minutes depending on data size. Larger datasets may take longer.

Q: Can I access the system from mobile?

Yes! The interface is fully responsive and works on tablets and smartphones.

Q: Who can access the system?

Only users added by the administrator can log in. Contact admin for access.
